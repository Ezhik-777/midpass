# Запуск midpass в Docker

Готовая Docker-сборка midpass-бота: ставится одной командой, дальше работает сама в фоне, раз в час сама подтверждает заявку в листе ожидания q.midpass.ru.

## Что нужно заранее

1. Сервер или домашний компьютер с **Docker** и **Docker Compose** (Linux, macOS, Raspberry Pi — что угодно).
2. Аккаунт на сайте [q.midpass.ru](https://q.midpass.ru) (email + пароль).
3. Знать **COUNTRY_ID** и **SERVICE_PROVIDER_ID** своего консульства (значения для разных стран есть в основном README проекта).
4. Аккаунт на **[rucaptcha.com](https://rucaptcha.com)** (он же 2captcha.com) с балансом от ~$1. После редизайна q.midpass.ru в 2026-м встроенный решатель капчи не работает, без сервиса распознавания не обойтись. Один прогон бота расходует примерно $0.003–0.005, баланса хватает надолго.

## Установка

```bash
# 1. Скачать
git clone -b deploy https://github.com/Ezhik-777/midpass.git
cd midpass

# 2. Создать конфиг и заполнить своими данными
cp config.txt.example config.txt
nano config.txt          # или любой другой редактор

# 3. Запустить — соберётся образ и поднимется контейнер в фоне
docker compose up -d

# 4. Посмотреть логи (Ctrl+C чтобы выйти, контейнер продолжит работать)
docker logs -f midpass-bot
```

В `config.txt` обязательно заполнить:

```
EMAIL=...                              # ваш email на q.midpass.ru
PASSWORD=...                           # пароль оттуда же
COUNTRY_ID=...                         # GUID страны
SERVICE_PROVIDER_ID=...                # GUID консульства
TIMEZONE=Europe/Berlin                 # ваша таймзона
RUCAPTCHA_API_KEY=...                  # ключ из личного кабинета rucaptcha
```

## Что делает контейнер

- При старте делает случайную задержку до 5 минут (чтобы не стучать в одну и ту же секунду каждый час).
- Каждые ~60 минут проверяет: есть ли заявка в листе ожидания, и нужно ли её сегодня подтвердить.
- Если заявка уже подтверждена в текущем 24-часовом окне — просто завершает цикл и ждёт следующего часа, не нагружая сайт.
- Если нужно подтвердить — логинится, подтверждает, выходит. Капчу решает через rucaptcha.
- Все действия пишутся в `data/logs/confirm-queue.log` (видны через `docker logs`).
- При перезагрузке хоста контейнер сам поднимется обратно (`restart: unless-stopped`).

## Управление

```bash
docker compose logs -f          # смотреть логи в реальном времени
docker compose restart          # перезапустить (после правок config.txt)
docker compose down             # остановить и удалить контейнер
docker compose up -d --build    # пересобрать образ и перезапустить
```

После любых правок `config.txt` достаточно `docker compose restart` — пересборка не нужна, конфиг подключён томом.

## Безопасность

- `config.txt` содержит ваш пароль и ключ rucaptcha — он в `.gitignore`, в репозиторий не попадёт.
- Бот не открывает никаких портов наружу: контейнер делает только исходящие HTTPS-запросы на q.midpass.ru и rucaptcha.com.
- Образ собирается локально из исходников, никаких сторонних бинарей не подтягивается, кроме официального релиза `gugglegum/midpass` v1.0.4.
